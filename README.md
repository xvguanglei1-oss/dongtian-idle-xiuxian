# 闲人修仙（Idle Xiuxian）

一款基于《凡人修仙传》世界观改编的 **Web 放置修仙游戏**。主身闭关涨修为、下山斗法以战证道；化身云游替主身跑腿搜罗材料——全程挂机，离线亦在成长。

纯前端单页应用 + 云存档服务，浏览器直接打开即玩。

## ✨ 特性

- **十二大境修行体系**：凡人 → 炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙 → 天仙
- **主身 = 斗法**：在线巡猎自动遇妖，逐合文字斗法（可速战），胜得灵石/修为/同级法宝
- **化身 = 云游**：出门即走、关页亦行，离线替你搜罗药草灵石、丹方残页与见闻，雁足寄回或归来结算
- **鸿雁信匣**：化身在外的收获以书信寄回，展信收取才真正归你
- **阿青打铁**：守家灵狐自动炼宝、择优穿戴，旧宝熔回灵石，全程无需手动
- **手动渡劫**：渡劫是进入下一卷的唯一方式（核心规则），成败看运气与根基
- **纪事里程碑**：灵石积累、聚灵阵升级、斗法战绩等事件写入修行录
- **修为系统**：聚灵阵收益随等级软顶；离线照常结算（云存档权威对账）

## 🎮 快速开始

```bash
# 任意静态服务器均可
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接用浏览器打开 `index.html`。

## 🗂 项目结构

```
├── index.html          # 主界面：双栏日志/修行录/境界/按钮
├── game.js             # 核心玩法：境界数值、剧情、里程碑、存档(寿命22s)
├── fx2d.js             # 玩家身上灵气特效（Canvas 2D 粒子/流光引擎）
├── bg.js               # 深空背景（three.js WebGL：星云/银河/仙月）
└── assets/
    ├── cultivator_*.png  # 打坐修士立绘（发/身/袍）
    ├── main-bg.jpg       # 深空主背景
    └── fx/               # 柔光/光晕/金尘贴图
```

## 🧙 修行提示

- 修为靠**挂机**：开着页面或离线都涨，离线进度以"寿命 22 秒"概念折算
- **手动点击渡劫**：炼气 13 层圆满后可渡劫入筑基，境界越高光效越华丽
- 剧情「不剧透」：右栏写你亲身经历，左栏写分身所见
