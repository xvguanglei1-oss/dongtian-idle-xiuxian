# 洞天·挂机修仙（Dongtian Idle Xiuxian）

一款基于《凡人修仙传》世界观改编的 **Web 放置修仙游戏**。打坐挂机自动涨修为，手动渡劫突破境界——玩家是凡人，从入洞天开始，一路修到化神。

纯前端单页应用，无构建、无后端，浏览器直接打开即玩。

## ✨ 特性

- **六境修行体系**：凡人 → 炼气（1~13 层）→ 筑基 → 结丹 → 元婴 → 化神，每境绑定专属剧情
- **100 个剧情节点**：随境界进度解锁，离线挂机也能推进当前卷剧情
- **手动渡劫**：渡劫是进入下一卷的唯一方式（核心规则），渡劫成败全看运气与根基
- **纪事里程碑**：灵石积累、聚灵阵升级、第一件法宝等事件写入修行录
- **修炼日志**：主栏为寿命级持久记录，左栏为分身洞府事件，双轨叙事
- **修为系统**：聚灵阵收益随等级软顶；数值按 90 天可到化神重调
- **试光环**：随时预览各境界的灵气光效（特效调试入口，置于界面按钮中）

## 🎮 快速开始

```bash
# 任意静态服务器均可
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接用浏览器打开 `index.html`。

## 🗂 项目结构

```
├── index.html          # 主界面：双栏日志/修行录/境界/按钮
├── game.js             # 核心玩法：境界数值、剧情、里程碑、存档(寿命22s)
├── fx2d.js             # 玩家身上灵气特效（Canvas 2D 粒子/流光引擎）
├── bg.js               # 深空背景（three.js WebGL：星云/银河/仙月）
└── assets/
    ├── cultivator_*.png  # 打坐修士立绘（发/身/袍）
    ├── main-bg.jpg       # 深空主背景
    └── fx/               # 柔光/光晕/金尘贴图
```

## 🧙 修行提示

- 修为靠**挂机**：开着页面或离线都涨，离线进度以"寿命 22 秒"概念折算
- **手动点击渡劫**：炼气 13 层圆满后可渡劫入筑基，境界越高光效越华丽
- 剧情「不剧透」：右栏写你亲身经历，左栏写分身所见
