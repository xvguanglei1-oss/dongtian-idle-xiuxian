## 提炼要点(结构, 非文案)
- 品质6档+粉: 白50/绿20/蓝15/紫9/金5/红1/粉pink, 乘子 1.2/2/3/5/7/10/15
- 部位: weapon→攻+暴击, armor→血+防, accessory/sutra→全能; sutra译"法器"
- 数值 = 随机基础(攻10~50×lv, 血100~500×lv) × 装备等级 × 品质乘子
- 玩家: 4 槽装备 武器/护甲/饰品/功法; 背包点选手动穿戴(显示与当前属性差)
- 怪物: 攻=rand(50,150)×lv, 血=rand(100,500)×lv, 防=rand(1,15)×lv(1~144级)
